AMERICAN AUTOMOTIVE MECHANICS — 8-PAGE WEBSITE

FILES
1. index.html        Home page
2. services.html     Automotive services
3. repairs.html      Repairs and maintenance
4. diagnostics.html  Vehicle diagnostics
5. performance.html Performance and advanced systems
6. electric.html     Electric and hybrid vehicles
7. about.html        About the website
8. contact.html      Contact form demo
9. style.css         Shared responsive design
10. script.js        Mobile navigation and demo form behaviour

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html. It opens in Chrome, Edge or Firefox.
4. Use the navigation menu to move between all eight pages.

LIVE WEBSITE / PUBLISHING
The pages are linked locally and work together after extraction. To publish a public live website, upload the extracted folder to GitHub Pages, Netlify or another static hosting provider. The contact form is a front-end demo and must be connected to a form service or backend to receive messages.

IMAGES
This design uses image URLs from Unsplash, so an internet connection is needed for the photographs. The layout and page navigation work offline, but remote photographs will not appear offline.

CUSTOMIZE
Replace the sample email, phone number and service area on contact.html with real details before publishing.
